# Лингвич

Сайт и учебная платформа языковой школы: публичный сайт, запись на занятия,
личные кабинеты ученика и преподавателя, CRM владелицы.

Django 4.2, серверный рендеринг, без сборки фронтенда. Весь интерактив —
на ванильном JS поверх `fetch`; страницы не перезагружаются, но при выключенном
JS формы продолжают работать обычным POST.

---

## Быстрый старт

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env          # заполнить не обязательно: дефолты рабочие
python manage.py migrate
python manage.py load_placement_questions   # 50 вопросов теста уровня
python manage.py seed_demo                  # демо-данные, чтобы всё было видно
python manage.py runserver
```

После `seed_demo` доступны демо-аккаунты (пароль у всех `linguich2024`):

| Роль | Логин |
|---|---|
| Владелица (CRM + преподавание) | `owner@linguich.ru` |
| Преподаватель | `anna@linguich.ru` |
| Ученик | `+79130001001` |

Вход работает и по email, и по телефону — ученики стабильно помнят что-то одно.

## Что где лежит

```
apps/
  accounts/      пользователи и роли, вход по email/телефону, привязка Telegram
  school/        публичный контент: языки, курсы, акции, отзывы, заявки (лиды)
  scheduling/    группы, расписание, окна записи, уроки, посещаемость
  learning/      программы, модули, темы, материалы, домашние задания
  billing/       тарифы, абонементы, платежи, списания уроков
  placement/     адаптивный тест уровня
  notifications/ очередь уведомлений и её отправка
  cabinet/       представления кабинетов (своих моделей нет)
config/          настройки, URL-роутинг
static/css/      дизайн-система: tokens → base → components → site/cabinet
static/js/       app.js (ядро), quiz.js (тест), booking.js (запись)
templates/       public/, cabinet/, components/, registration/
```

### Три роли, один аккаунт

`User.role` — `student` / `teacher` / `owner`. Владелица тоже ведёт уроки,
поэтому `user.is_teacher` истинно и для неё: все преподавательские экраны
доступны без дублирования кода, а сверху добавляется раздел «Школа» с CRM.

## Ключевые решения

**Индивидуальные занятия — это группа на одного.** `Group.capacity == 1`.
Благодаря этому расписание, домашки, списания и отчёты работают одним кодом
и для групп, и для индивидуальных учеников.

**Запись и посещаемость — одна строка.** `LessonParticipant` хранит и факт
брони, и итоговый статус (был / не пришёл / отменил заранее). Не нужно
сверять две таблицы, чтобы понять, списывать занятие или нет.

**Два независимых счётчика денег.** У школы их правда два:
- *сколько должен* = сумма выданных абонементов − сумма платежей;
- *сколько уроков осталось* = купленные уроки − списанные.

Выдача абонемента создаёт начисление, платёж его гасит, проведённый урок
уменьшает баланс занятий. Отсюда честный список должников без ручного счёта.

**Отмены по правилам школы.** Раньше `FREE_CANCELLATION_HOURS` (по умолчанию 12)
отмена бесплатна, позже — занятие списывается. Отмена со стороны школы не
списывает ни у кого.

**Уведомления только в очередь.** Запрос никогда не ходит в SMTP или Telegram
напрямую — он кладёт запись в `Notification`, а разбирает очередь cron. Упавший
почтовый сервер не может сломать запись на урок. `dedupe_key` делает постановку
идемпотентной: планировщик напоминаний можно запускать хоть каждую минуту.

**Тест уровня действительно адаптивный.** Четыре вопроса на ступень CEFR, затем
шаг вверх, вниз или остановка. Сильный ученик доходит до C1 за ~12 вопросов,
слабому не выдают двадцать заданий, которые он не прочитает. Итоговый уровень —
самая высокая ступень, где взято не меньше половины. Результат раскладывается
по навыкам (грамматика, лексика, чтение, речевые ситуации) и превращается
в заявку в CRM.

## Регулярные задачи (cron)

```cron
# Отправка очереди уведомлений
* * * * *  cd /path/to/linguich && .venv/bin/python manage.py send_notifications

# Постановка напоминаний об уроках на ближайшие дни
*/15 * * * *  cd /path/to/linguich && .venv/bin/python manage.py schedule_reminders

# Материализация занятий групп по недельному расписанию
0 3 * * *  cd /path/to/linguich && .venv/bin/python manage.py generate_lessons --weeks 6
```

Все три команды идемпотентны — повторный запуск ничего не дублирует.

## Telegram-напоминания

1. Создайте бота у `@BotFather`, положите токен и имя в `.env`.
2. Пропишите вебхук:
   ```bash
   curl -F "url=https://linguich.ru/accounts/telegram/webhook/" \
        -F "secret_token=$TELEGRAM_WEBHOOK_SECRET" \
        https://api.telegram.org/bot$TELEGRAM_BOT_TOKEN/setWebhook
   ```
3. Ученик нажимает «Подключить Telegram» в профиле — бот получает `/start <код>`
   и привязывает чат к аккаунту.

Без токена система работает как обычно: Telegram-канал просто пропускается,
уведомления остаются в кабинете и уходят на почту.

## Дизайн-система

Всё перекрашивается из одного файла — `static/css/tokens.css`. Там же светлая
и тёмная темы: тёмная собрана отдельно, а не инверсией, и переключатель темы
побеждает системную настройку в обе стороны.

Логотип — `static/img/logo.svg` и инлайновая версия `templates/components/logo.html`
(она использует переменные темы, поэтому корректно смотрится и в тёмной).
Знак — тот же «глобус в облачке реплики», что был, но сведённый к чистой
геометрии: читается и на 16px, и на вывеске. Когда пришлёте исходные логотипы,
заменить нужно только эти два файла.

## Деплой

1. `DJANGO_DEBUG=False`, задать `DJANGO_SECRET_KEY` и `DJANGO_ALLOWED_HOSTS`.
2. `python manage.py collectstatic` — статику раздаёт WhiteNoise, отдельный
   nginx-alias не обязателен.
3. `python manage.py migrate`, затем `createsuperuser`.
4. Настроить cron из раздела выше.
5. Медиафайлы (аватары, домашки, материалы) лежат в `media/` — включить в бэкап
   вместе с базой.

В production автоматически включаются HSTS, secure-cookies и редирект на HTTPS
(`SECURE_SSL_REDIRECT` можно отключить, если TLS терминируется выше).

## Что осталось решить

- **Онлайн-оплата.** Сейчас платежи заносит владелица, система считает долги
  и выручку. Поля под эквайринг (`Payment.provider`, `provider_payment_id`)
  уже есть — подключение ЮKassa сводится к одному вебхуку.
- **Онлайн-уроки.** Платформа хранит ссылку на класс (у урока, у группы или
  постоянную у преподавателя) и собирает вокруг неё материалы и домашки.
  Своя видеосвязь не строилась намеренно: это отдельный продукт, а Zoom/Jitsi
  решают задачу лучше и бесплатно.
- **Логотипы.** Заменить два файла из раздела «Дизайн-система».
